# Autotyper icon

Generated with the built-in imagegen tool. Source: `Assets/AppIcon.png`.
The build script preserves alpha and generates the macOS ICNS size set.

## Final prompt

Use case: logo-brand. Asset type: production macOS application icon for Autotyper, a minimal menu bar utility that types text automatically. Create one clean, modern macOS-style icon: a softly rounded square tile with a simple sculpted keyboard key and an elegant text insertion cursor as its central symbol. Subtle dimensional depth, refined soft lighting, restrained blue accent with neutral key surface, crisp silhouette readable at 16 pixels. Straight-on centered view, generous internal spacing. No letters, words, branding, watermark, extra objects or presentation mockup. Square 1024x1024 image. Transparent outside the rounded-square tile, actual alpha transparency. The tile should occupy about 88 percent of the canvas.
